# شاشة IPTV

مشغل أندرويد مستقل يقرأ القنوات والأفلام والمسلسلات من لوحة PHP الموجودة على `https://x-men.wuaze.com/` عبر واجهة Xtream API التي توفرها اللوحة.

## الوظائف
- قنوات مباشرة، أفلام، ومسلسلات.
- تحميل تصنيفات المحتوى من اللوحة.
- عرض مواسم وحلقات المسلسلات.
- بحث محلي داخل القسم الحالي.
- تشغيل الروابط المباشرة وHLS باستخدام AndroidX Media3 / ExoPlayer.
- لا يحتاج تسجيل دخول المدير؛ يستخدم حساب تشغيل Xtream المخصص الموجود في إعدادات اللوحة.

## البناء
- Android SDK 35
- JDK 17
- Gradle 8.9
- افتح المشروع في Android Studio أو شغّل `gradle assembleDebug`.

GitHub Actions يبني نسخة Debug تلقائيًا عند كل push ويرفع APK كـ artifact. التطبيق يتطلب اتصال إنترنت واستضافة متاحة، ولا يتضمن أي محتوى وسائط.
