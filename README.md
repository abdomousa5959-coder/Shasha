# شاشة IPTV

مشغل أندرويد يتصل مباشرة بلوحة عائلتنا على `https://x-men.wuaze.com/`.

## طريقة الاتصال
- يستخدم واجهة الإدارة الرسمية `api.php` في اللوحة.
- عند أول تشغيل، سجّل الدخول ببيانات مدير اللوحة.
- يستخرج التطبيق القنوات والأفلام والحلقات من `api.php?action=items` بعد نجاح تسجيل الدخول.
- يحافظ على جلسة PHP وCSRF token عبر CookieManager.
- لا يخزن كلمة المرور داخل APK أو المستودع.

## الوظائف
- القنوات المباشرة.
- الأفلام.
- المسلسلات وتجميع الحلقات حسب المسلسل.
- البحث داخل القسم.
- تشغيل الروابط المسجلة في اللوحة باستخدام AndroidX Media3 / ExoPlayer.
- لا يحتاج Xtream credentials منفصلة.

## البناء
- Android SDK 35
- JDK 17
- Gradle 8.9
- `gradle assembleDebug`

GitHub Actions يبني نسخة Debug تلقائيًا ويرفع APK كـ artifact.
